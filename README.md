# Traditional Chinese Converter for GT:New Horizons
繁體中文轉換器，自動轉換 GT:New horizons 模組包內所有含 zh_CN 的語言檔

*支援自訂字典(dictionary.txt)進行慣用語翻譯修正

*支援最新遊戲內百科(GuideNH)的繁體轉換

前置作業:

1. 在電腦上安裝Python，3.10以上版本即可。
2. 打開 cmd 或 PowerShell 輸入執行：pip install opencc-python-reimplemented
3. 於以下網址下載最新釋出簡中漢化補丁並完成安裝: https://github.com/Kiwi233/Translation-of-GTNH/releases

使用說明:

1. 下載完整zip檔後，將檔案解壓縮。
2. 開始轉換前請確認遊戲為關閉狀態，否則將無法轉換成功。
3. 點擊啟動run.bat，輸入你想轉換的GTNH資料夾位置，例如：D:\.Minecraft\PrismLauncher\instances\GT_New_Horizons_2.8.4_Java_17-25。
4. 等待程式跑完，開啟遊戲並將語言切換到繁體中文，退出遊戲再重進。
5. Enjoy:)

⚠️ 經測試應不影響原本文件，若有疑慮可以先備份再進行轉換。
